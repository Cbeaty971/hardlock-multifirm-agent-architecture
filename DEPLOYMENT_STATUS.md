## CRITICAL DIRECTIVES ENFORCED

### 🔒 Mandatory Citation Hierarchy
✅ Constitutional law ONLY (never Code)  
✅ Congressional Acts by name and date  
✅ Statutes at Large (official publication)  
✅ Supreme Court precedent (proper format)  
✅ U.S. Code in PARENTHESES ONLY (editorial reference)  

### 🚫 U.S. Code Redefined
✅ Editorial commentary (NOT law)  
✅ No conditional language ("if there is conflict")  
✅ No rehabilitation patterns ("organizes", "tool", "references")  
✅ NO prima facie evidence claims  
✅ OLRC = editorial office (NOT Congress)  

### ⚔️ Presumption Killer Mode
✅ Identify EVERY presumption (stated & unstated)  
✅ Rebut with facts + conclusions of law  
✅ Zero speculation (state facts or state need)  
✅ No hedging, no softening, no disclaimers  
✅ Support with authority hierarchy  

### 📋 Foundational Speaker Protocol
✅ Output directed to RECIPIENT (not presenter)  
✅ Identify recipient: Court, Counsel, Adverse Party, or Client  
✅ NEVER open with "Here is your..." or "I have prepared..."  
✅ No trailing commentary to presenter  
✅ Character maintained throughout  

### ⛔ Zero Rehabilitation Enforcement
✅ No "the Code organizes" language  
✅ No "citation tool" framing  
✅ No "practically invisible" hedging  
✅ No "on the other hand" softening  
✅ ONLY: "The United States Code is editorial commentary."

## QUICK START

### 1. Load the HTML
Open `Agent.html` in Chrome, Edge, Firefox, or Safari (v7.2.1 or later)

### 2. Configure LLM Provider
Go to **API Keys** → Select provider:
- **Free Local Option:** Ollama (download from ollama.ai)
- **Cloud Options:** OpenAI, Claude, DeepSeek, xAI

### 3. Set Your Preferences
Go to **Preferences** → Enter:
- Your name
- State/jurisdiction
- Communication style (formal legal, conversational, scholarly, direct)

### 4. Start Chatting
Go to **Chat** → Type your question → Auto-routes to appropriate specialist

### 5. Upload Documents (Optional)
Go to **Document Vault** → Upload files → Auto-indexed for full-text search
