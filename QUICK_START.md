# E2ZERO Agent v7.2.1 — QUICK START GUIDE

## 60-Second Setup

### Step 1: Open Agent.html
```
Double-click Agent.html in your browser
(Chrome, Edge, Firefox, Safari v7.2.1+)
```

### Step 2: Configure LLM
Go to **API Keys** tab:
- **Option A (Free):** Ollama
  - Download: https://ollama.ai
  - Run: `ollama pull qwen3:8b`
  - URL: `http://127.0.0.1:11434`
  
- **Option B (Paid):** OpenAI, Claude, DeepSeek, xAI
  - Get API key
  - Paste in corresponding field
  - Click "Save All Keys"

### Step 3: Set Your Details
Go to **Preferences**:
- Enter your name
- Enter your state/jurisdiction
- Choose communication style (Formal Legal recommended)
- Click "Save Preferences"

### Step 4: Start Chatting
Go to **Chat**:
- Type your question
- Press Enter or click ➤
- System auto-routes to appropriate specialist agent

## Troubleshooting

### "LLM: not configured"
**Fix:** Go to **API Keys** → Select Ollama (local) or paste API key → Save

### "No documents indexed"
**Fix:** Go to **Document Vault** → Upload .txt or .pdf files → Click "Rebuild Index"

### "Chat not responding"
**Fix:** 
1. Check LLM provider is working
2. Go to **API Keys** → Click "🔍 Test Connection"
3. Verify API key is correct
4. Try different provider

### "Voice not working"
**Fix:** Chrome/Edge required (not Safari for speech-to-text)

### "Storage full"
**Fix:** Go to **Backup** → "🗑 Factory Reset" (exports data first)

## SYPHER Protocol (What It Means)

SYPHER Protocol v7.1 means:

✅ **Facts + Law Only** — No speculation, no assumptions  
✅ **Constitutional Priority** — U.S. Constitution is supreme law  
✅ **Congressional Acts First** — Not the U.S. Code  
✅ **Statutes at Large** — Official Congressional publications  
✅ **Supreme Court Precedent** — Binding case law  
✅ **U.S. Code (Parentheses Only)** — Editorial reference, not primary law  
✅ **No Hedging** — "likely," "probably," "seems" are prohibited  
✅ **Zero Disclaimers** — No "I am an AI" language  
✅ **Presumption Killer** — Every presumption identified and rebutted  

**Result:** Answers that are legally precise, fact-based, and un-hedged.
